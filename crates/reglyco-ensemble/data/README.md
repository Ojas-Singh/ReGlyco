# Dunbrack rotamer subset

`dunbrack-supported-top10.tsv.gz` contains the ten highest-probability
backbone-dependent rotamers per 10° φ/ψ bin for ASN, SER, THR, and TRP. It was
mechanically extracted from `ALL.bbdep.rotamers.lib` used by GlycoShape
Cookbook.

Source: Shapovalov MV, Dunbrack RL Jr. *Structure* 2011, 19(6):844–858.
The source rotamer library is distributed under CC BY 4.0.
